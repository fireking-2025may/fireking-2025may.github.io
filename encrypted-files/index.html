The files in this folder contain encrypted ciphertext. Enter the password to decrypt them locally in this browser—your password and the readable text are never sent to a server.

Decryption uses AES-256-GCM and a PBKDF2-SHA-256 key derived separately for every file. Static hosting can protect data at rest, but it cannot hide file count or prevent offline password guessing; use a long, unique password.
